# Novel Maker

Codexに長編小説を一話ずつ継続して書かせるための、シンプルなリポジトリテンプレートです。ユーザーは一話ずつ内容を確認しながら依頼することも、指定した複数話を一度に任せることもできます。

本文とは別に、あらすじ、人物、場所、現在の状態をファイルへ保存します。毎回すべての本文を読み直すのではなく、必要な情報を外部記憶として引き継ぐことで、長編化した際の混乱やコンテキストの肥大化を抑えます。

## 使い方

1. このリポジトリ一式を、執筆する作品用のフォルダへコピーします。
2. `start.md` に、ジャンル、世界観、登場人物、話数、文字数など、決まっている希望を書き込みます。決まっていない項目は空欄のままで構いません。
3. Codexで、そのフォルダをローカルプロジェクトとして開きます。
4. 新しいタスクを開始し、次のように依頼します。

> AGENTS.mdに従い、start.mdの内容を基に初期設定ファイルを完成させてください。未決定のままでは執筆内容が大きく変わる点だけ確認してください。まだ本文は書かないでください。

5. 初期設定が完成したら、希望する範囲の執筆を依頼します。

`start.md` を自分で編集せず、希望をCodexへ伝えて「内容を `start.md` に記入してください」と依頼しても構いません。

## 執筆の頼み方

一話ずつ読みながら進める場合：

> 第1話を執筆してください。完成後、AGENTS.mdに従って要約と現在状態も更新してください。

複数話を一度に任せる場合：

> 全20話を執筆してください。全体の流れを先に整理し、一話ごとの執筆・要約・状態更新を20回繰り返して、途中確認なしで最後まで進めてください。

ユーザーが20話を一度に依頼しても、Codexが20話分の本文を先にまとめて書くわけではありません。「一話を書く、要約と現在状態を更新する、次の一話を書く」という同じ工程を20回繰り返します。

エージェントの正式な作業手順と禁止事項は [`AGENTS.md`](AGENTS.md) に定義されています。

## 構成

```text
AGENTS.md                    エージェントの作業規約
start.md                     作品の出発条件

canon/
  world.md                   世界設定
  characters.md              人物の基本設定と話し方
  locations.md               場所の恒常的な設定

state/
  current.md                 最新話終了時点の状態

summaries/
  running-summary.md         ここまでの短い累積あらすじ
  episodes/                  各話の保存用要約

manuscript/                  各話本文
templates/                   執筆前メモと各話要約の雛形
```

## 内部の処理

```text
設定・現在状態・要約を読む
          ↓
一話分の本文を書く
          ↓
各話要約を保存する
          ↓
累積あらすじと現在状態を更新する
          ↓
本文と更新内容を照合する
          ↓
依頼された話数に達していなければ次の一話へ
```

人物の基本性格と現在の感情、場所の設定と人物の現在地など、変わらない情報と変化する情報を分離して管理します。

## 設計方針

このテンプレートは、最初からあらゆる情報を管理することを目指していません。依頼された話数にかかわらず一話単位の工程を守り、まずは次の連続性を保ちながら複数話を書き続けられることを目的としています。

- 人物の性格、呼称、話し方
- 人物と重要物品の現在位置
- 身体や感情、人間関係の変化
- 場所同士の位置関係
- 時間経過と前話からのつながり

伏線、詳細な時系列、人物ごとの知識状態などは、必要になった段階で追加する想定です。使う前から管理項目を増やさず、実際に発生した問題に応じて仕組みを拡張します。

## 現在の位置づけ

長編制作を実際に継続できるか検証するためのプロトタイプです。生成された本文と更新内容は、必要に応じて人間が確認・修正してください。
